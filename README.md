# faxbird-site

Legal pages for **Fax**, the iPhone app by PocketCraft OÜ — Privacy Policy, Terms of Use and Contact, served at `https://fax.pocketcraft.site`. Plain HTML and CSS in `public/`, no build step and no third-party requests: the site deploys through Cloudflare Pages connected to this repository (framework preset None, empty build command, build output directory `public`), and every push to `main` redeploys.
